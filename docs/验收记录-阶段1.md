## 三、偏差记录（均已修正并同步文档）

| 偏差 | 原因 | 处理 |
|---|---|---|
| 后端端口 8100 → **8101** | 8100 在本机 bind 报 `WinError 10013`（被系统保留） | 改配置、README、设计文档；`test_config` 断言同步 |
| bge-m3 缓存为空壳 | 原目录只有 `refs/main`，无权重 | 脚本下载 2166MB，`--check` 增加真实文件校验 |
| 镜像下载 401 | huggingface_hub 2.x 默认走 Xet(CAS)，镜像不代理 | 子进程强制 `HF_HUB_DISABLE_XET=1` |
| reranker 下载失败 | 本机代理 502 / 直连超时，网络间歇中断 | 从本机 `Itcast_qa_system` 复制现成权重，并加 safetensors 截断校验 |
| `qa_pairs` 全文索引 | MySQL FULLTEXT 不支持 JSON 列 | 增加冗余 `search_text TEXT` 承载 ngram 索引（设计文档 §2.4 已修正） |
