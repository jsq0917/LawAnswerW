## 三、调试中发现的真问题（已修，值得记录）

1. **并发 GPU 推理静默产出零向量**：Windows 内存提交超限（os error 1455 页面文件太小）
   时，FlagEmbedding 的并发 forward 可能不抛错而是产出零向量 → Milvus 返回 0 候选 →
   P6 组评测曾全零。修法：embedder/reranker 加推理锁（GPU 本就串行执行 kernel，
   无吞吐损失）+ retrieve_multi 部分降级（个别子查询失败不拖垮整体）。
   **本机背景**：vmmemWSL（Docker）占 15GB、提交内存 88.5GB 只剩 ~6GB，跑模型时
   建议关掉不用的桌面应用或扩大页面文件。
2. **意图缓存污染生产 Redis**：单测 fixture 数据被写进本机 Redis db3。
   conftest 已加全局离线 Redis 夹具（fail-open 分支接管）。
